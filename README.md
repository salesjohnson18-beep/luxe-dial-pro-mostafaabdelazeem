# Luxe Dashboard Pro

أريد بناء نظام تشغيل ولوحة تحكم متكاملة لإدارة عمل ميديا باير وبيرفورمانس ماركتير (مصطفى عبدالعظيم) بتصميم فاخر أسود وذهبي (Black & Gold / Dark Luxe) وواجهة عربية كاملة RTL سلسة وسهلة الاستخدام، وفق المتطلبات المحددة التالية:

1. التصميم والهوية البصرية (مطابق للاسكرينات المرفقة):
- ثيم أسود وذهبي داكن أنيق وفخم (Dark Luxe).
- كارت تقرير العميل اليومي:
  - اسم العميل/المشروع، التاريخ، Performance Report.
  - شبكة مقاييس (4×2): الصرف (SPEND)، الإيراد (REVENUE)، العائد (ROAS)، المشتريات (PURCHASES)، تكلفة التحويل (CPA)، تكلفة النقرة (CPC)، نسبة النقر (CTR)، نسبة التحويل (CONV. RATE).
  - أشرطة أداء ونسب المنصات الإعلانية.
  - التوقيع بالأسفل باسمي فقط: MOSTAFA ABDELAZEEM بدون أي عبارات إضافية.
  - زر تحميل الكارت كصورة جاهزة للواتساب، وزر نسخ رابط مباشر للتقرير التفاعلي بدون حاجة لدخول العميل بحساب.
  - فلتر تحديد التاريخ (يومي / شهري / مخصص).
- لوحة التحكم العامة: مؤشرات مجمعة بالريال السعودي، رسم بياني للصرف مقابل الإيراد يومياً، وتوزيع الصرف وأداء المنصات.

2. المصادقة والأدوار والصلاحيات (Auth & Roles):
- تسجيل دخول متكامل بإيميل وكلمة مرور وكود تحقق.
- أول حساب يتم إنشاؤه على النظام هو تلقائياً الأدمن (Admin / Owner) وله الصلاحيات الكاملة.
- الأدمن يدير المستخدمين ويحدد أدوارهم وصلاحياتهم:
  - Admin (مدير النظام كامل الصلاحيات).
  - Media Buyer (إدخال بيانات الحملات، إدارة العملاء المسندين إليه، ومختبر الأفكار).
  - مبيعات / خدمة عملاء (إدارة كروت المتابعة وعروض الأسعار والعملاء المحتملين).
  - محاسب (إدارة التحصيلات، الدفعات، الفواتير والمصروفات، بدون الوصول لكلمات سر العملاء أو تعديل بيانات الحملات).

3. إدارة العملاء وبروفايل العميل:
- في قسم العملاء: خانة منفصلة باسم العميل نفسه، وخانة باسم المشروع بتاعه.
- خانة خاصة بمجال العميل (مثل: محل ورد، شركة تنظيف، متجر عطور، عبايات، مطعم/كافيه، متجر إلكتروني، مركز طبي...) مع خيار "أخرى..." يتيح كتابة المجال يدوياً.
- تحديد نوع التعاقد: (فري لانس أو دوام كامل).
- دورة التحويل: (أسبوعي أو شهري).
- استيراد ملفات إكسل: إمكانية رفع شيت إكسل للحملات التاريخية السابقة عند إنشاء أو تعديل بروفايل العميل وحفظ كل الداتا السابقة.
- النظام يبدأ بدون أي داتا تجريبية أو وهمية (Zero dummy data).
- خزانة آمنة لحفظ كلمات المرور والروابط والخطط.
- تفعيل/تعطيل اختياري لورقة الأداء الشهري وحاسبة تسعير المنتجات والمخزون.

4. إدخال الحملات اليومية ومؤشرات المتجر:
- إدخال سريع يومي لأرقام الحملات: الصرف، النقرات، الظهور، المشتريات، الإيراد.
- حساب تلقائي لباقي المؤشرات: ROAS, CPA, CPC, CPM, CTR, Conv. Rate.
- دعم المنصات: Google Ads, Meta, Snapchat, TikTok, Twitter/X مع صف إجمالي مجمع تلقائي لقنوات الإعلانات المدفوعة (PAID CHANNELS).
- خانات لمبيعات المتجر الفعلية لحساب الـ Blended ROAS الحقيقي مقارنة بأرقام المنصات.

5. الـ CRM وعروض الأسعار وكارت المتابعة:
- دليل خدمات لإنشاء وإدارة باقات الخدمات وأسعارها.
- إدارة عروض الأسعار: إنشاء عرض سعر لعميل حالي أو عميل جديد، تحديد نوع الدفع (مقدم كامل للخدمات المصغرة، أو أسبوعي بعدد دفعات، أو شهري)، إمكانية تعديل العرض أثناء التفاوض، ومشاركته برابط مباشر للموافقة.
- كارت المتابعة (مطابق للصورة): بيانات العميل والمسؤول، أزرار اتصال وواتساب سريعة، سجل متابعات زمني، حالات (قيد المتابعة، تم التنفيذ، ملغي).
- عند اختيار خيار "أخرى..." في نتيجة المتابعة يفتح حقل لكتابة الملاحظة وحفظها في السجل.
- عند اختيار "تم التنفيذ" يتحول تلقائياً لبروفايل عميل نشط.

6. متابعة الماليات والدفعات:
- في متابعة الدفعات المستحقة: توضيح قيمة الدفعة بالتحديد ورقمها (مثلاً: الاتفاق 800 -> الدفعة المستحقة 200 ر.س - الدفعة 1 من 4).
- تنبيهات النظام بالسؤال عما إذا كان العميل دفع الدفعة لتحديث حالتها.
- سجل للمقبوضات والمصروفات وصافي الأرباح.

7. التنبيهات وإدارة المهام:
- تنبيهات صوتية حقيقية (رنة جرس واضحة) بجانب التنبيهات المرئية.
- تنبيه التحويل الأسبوعي: يبدأ العد بعد 7 أيام من تاريخ بدء إدخال بيانات الحملات لتذكيري بإرسال رسالة التحويل للعميل.
- قسم خاص لحملاتي وإعلاناتي الشخصية (مثل تذكير يومي بتجديد إعلانات حراج، وحملاتي الخاصة).
- تنبيهات متكررة (مثل تجديد ليمت الحسابات الإعلانية المحدودة) وتنبيهات لمرة واحدة.
- إدارة مهام يومية متكررة وفردية مع إمكانية إنشائها بالأوامر.

8. الذكاء الاصطناعي ومختبر الكرييتف (Hooks Lab):
- قسم داخل بروفايل العميل "مختبر الكرييتف والأفكار": توليد هوكات أول 3 ثوانٍ للفيديو حسب المنصة، زوايا إعلانية، ونصوص إعلانية وكابشن، مع بنك لحفظ الأفكار المعتمدة.
- قراءة الأرقام اليومية واقتراح إعادة توزيع الميزانيات والتنبيه بهبوط الـ CTR وتشبع الإعلانات.
